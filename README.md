# Backend FSD Coursework

This repository contains the backend coursework, assignments, and practical implementations for the Full Stack Development (FSD) course.

## Repository Structure

- **/ASSIGNMENT/**: Contains the official, protected assignment submissions.
  - `node_test_Assignnment1`
  - `productrestapi_Assignment2`
  - `portfolio_Assignment3`
  - `Assignment4`

- **/CLASSWORK/**: Contains topic-wise class practicals and exercises.
  - `Express_HTML` - Demonstrates serving static HTML files.
  - `Express_REACT` - Express API connected to a React frontend.
  - `Node_Test` - Contains foundational Node.js exercises.
  - `express_module` - Basic Express application setup and routing implementations.
  - `productrestapi` - An initial REST API utilizing Express.js.
  - `server` - Core HTTP server demonstrations.

## Technologies Used
- JavaScript (Node.js)
- Express.js
- EJS / React (for frontend coursework integrations)

## Running the Practicals

Each folder inside `CLASSWORK` is self-contained. To run a practical:

1. Navigate to the practical's directory (e.g., `cd CLASSWORK/productrestapi`).
2. Install the necessary dependencies (only needs to be done once per folder):
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm start
   ```
   *(Note: Some practicals like `productrestapi` also support `npm run dev` to start with Node's native watch mode).*
